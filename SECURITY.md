# Security

Seed is a personal project with a live Firebase backend. If you find a
vulnerability, please do not open a public issue. Report it privately
via GitHub's "Report a vulnerability" form on this repository's
Security tab, and allow a reasonable window for a fix before any
disclosure.

The server-side security posture (Firestore rules, App Check, Cloud
Functions hardening) and the status of past audit findings are
documented in [Plan/SECURITY_REPORT.md](Plan/SECURITY_REPORT.md).
